# Documentation map

- `design/` — numbered product and interaction specifications.
- `api/` — the generated code reference (`npm run docs`, TypeDoc). Not tracked. Published under
  `api/` on the project site, https://zhubbs19.github.io/RerunTV/ (`.github/workflows/pages.yml`).
- `typedoc/` — the code reference's look: its stylesheet, the site header bar and icons.
- `../site/` — the site's landing page; `npm run site` builds the whole site into `_site/`.

Plugin authors: see `../PLUGIN_DEVELOPMENT.md`. Contributor and agent guidance: `../CLAUDE.md` and `../AGENTS.md`.
