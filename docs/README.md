# Documentation map

- `architecture/` — system boundaries and core design decisions.
- `audits/` — dated audits, investigations, and resolved defects.
- `design/` — numbered product and interaction specifications.
- `features/` — feature designs and implementation notes.
- `integrations/` — companion, LAN, and third-party service work.
- `operations/` — installation, portable data, and real-app test guidance.
- `plugins/` — plugin platform design and migration notes.
- `project/` — roadmap, repository, parity, and workflow notes.

`MEMORY.md` remains the historical index for prior implementation context.
